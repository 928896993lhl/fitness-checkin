# 测试用例文档

## 测试用例概述

### 测试目标
验证健身打卡小程序后端的功能完整性、正确性和健壮性。

### 测试环境
- Java 17+
- Spring Boot 3.2.5
- MySQL 8.0
- Maven 3.6+

### 测试范围
1. 单元测试
2. 集成测试
3. API接口测试
4. 安全测试
5. 性能测试

## 1. 用户认证测试用例

### TC-1.1: 微信登录成功
**测试步骤**:
1. 调用 `POST /api/auth/wx-login`
2. 传递有效的微信code

**预期结果**:
- 返回状态码 200
- 返回token和用户信息
- 用户信息保存到数据库

### TC-1.2: 微信登录失败 - 无效code
**测试步骤**:
1. 调用 `POST /api/auth/wx-login`
2. 传递无效的微信code

**预期结果**:
- 返回状态码 400
- 返回错误信息

### TC-1.3: 获取用户信息
**测试步骤**:
1. 使用有效token调用 `GET /api/auth/user-info`

**预期结果**:
- 返回状态码 200
- 返回当前用户信息

### TC-1.4: 刷新token
**测试步骤**:
1. 使用有效token调用 `POST /api/auth/refresh-token`

**预期结果**:
- 返回状态码 200
- 返回新的token

## 2. 圈子管理测试用例

### TC-2.1: 创建圈子成功
**测试步骤**:
1. 使用有效token调用 `POST /api/circles`
